# Resume bullets

Use these after reading and understanding the implementation. This is an independent portfolio project, not work performed for ModMed.

- Built CareFlow, a React/TypeScript and FastAPI portfolio application for fictional patient registration, appointment scheduling, and doctor-reviewed documentation backed by PostgreSQL.
- Implemented PostgreSQL-backed rescheduling with appointment version checks, atomic history/audit updates, and idempotent request replay; verified the application with 46 backend tests and six desktop/mobile browser checks.
- Integrated a deterministic mock assistant and optional structured-output adapter with stale-response protection, plus a 25-case fictional evaluation harness with spending guards and human-review sheets; live-model evaluation remains unrun.

Do not add adoption, time-savings, clinical accuracy, compliance, production scale, or live evaluation claims. Those outcomes were not measured.
